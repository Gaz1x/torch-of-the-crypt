# Game Dev Starter

Стартовый проект для курса **«Проектирование и разработка игровых приложений»**.

Стек: **TypeScript + Phaser + Vite + GitHub Pages**.

Проект — браузерная игра **«Последний факел крипты»**: рыцарь с факелом стоит в темноте крипты, из трещин в стенах появляются тени, свет факела замедляет их, а выстрелы сгустками света расходуют ману. Партия состоит из **десяти волн на трёх этажах**: «Сухие галереи», «Затопленные склепы» и «Пепельный трон». На каждом этаже свой набор теней, а после него игра замирает и предлагает выбрать один из **даров** — усиление до конца спуска. В финале выходит босс — **Пожиратель Пламени**, который гасит факел, бросается в рывок и звереет на половине здоровья. Пока босс жив, он постоянно призывает свиту — она даёт ману, но не даёт спокойно стоять на месте. Фазы переключаются по очкам: набрано 25 очков — факел гаснет, набрано ещё 15 — он загорается снова, а в темноте персонаж движется медленнее.

Между спусками рыцарь возвращается в полноэкранный **лагерь**. За забег начисляется **Эхо**: `очки / 2 + 20 за каждого убитого босса`; победа приносит полную награду, смерть — половину. Эхо тратится на постоянные улучшения — максимум здоровья, стартовую ману и радиус света. Профиль и купленные улучшения сохраняются в `localStorage`.

Задание первой практики и домашней работы: [`ASSIGNMENT_01.md`](./ASSIGNMENT_01.md).

### Интерфейс

- **лагерь** — полноэкранный хаб с логотипом, бразиером и сидящим стражем у огня, кнопками справа: «Спуститься», «Улучшения», «Настройки», «Памятка»; в центральной арке время от времени появляются силуэты монстров;
- в правой колонке лагеря — карточка **«Хроника стража»**: Эхо, ранг, спуски, победы и лучший счёт;
- **слева — «Страж»**: этаж, здоровье и мана;
- **в центре — «Факел»**: текущая фаза и прогресс до следующей, под ним появляется полоса босса;
- **справа — «Хроника»**: этаж, волна, остаток врагов, очки, время и убийства;
- границу круга света очерчивает двойное кольцо: янтарное при горящем факеле и багровое во тьме;
- в лагере под описанием мира по очереди сменяются короткие слоганы;
- после каждого из трёх этажей открывается окно **«Дары этажа»** с тремя карточками из четырёх даров: «Скорое пламя», «Раздвоенный луч», «Пронзающая искра» и «Стойкость»; выбранный дар действует до конца спуска;
- начало волны и смена фазы показываются отдельными карточками, которые не перекрывают меню;
- на экранах победы и поражения выставляется ранг **S / A / B** и показывается, сколько Эха принёс спуск;
- окно **«Улучшения»** показывает три постоянных улучшения, их уровень, цену и текущее Эхо;
- на экранах лагеря и паузы есть **«Памятка»** с управлением и **«Настройки»** с громкостью музыки и звуков;
- в боссовой волне строка «Осталось» заменяется на **«Свита: N»**.

Вся графика интерфейса рисуется процедурно, без внешних ассетов и шрифтов. Музыкальный трек лежит в `src/assets/audio/soundtrack.mp3`, играет по кругу и запускается после первого клика или нажатия клавиши — этого требуют браузеры.

### Управление

- **WASD / стрелки** — движение;
- **курсор мыши** — направление взгляда и прицела;
- **левая кнопка мыши или пробел** — выстрел сгустком света (15 ед. маны);
- **ESC** — пауза: продолжить игру, начать заново или вернуться в лагерь;
- с убитых врагов падают **кристаллы маны**;
- за спуск начисляется **Эхо**; в лагере его можно потратить на постоянные улучшения здоровья, стартовой маны и радиуса света;
- внутри круга света враги **сильно замедляются**;
- после попадания рыцарь получает **1 секунду неуязвимости** (мигание и голубое кольцо): в это время касание врага не наносит урона, не отбрасывает врага и не убивает его;
- у каждого врага есть пауза между касаниями, поэтому толпа не снимает всё здоровье за один кадр;
- волна заканчивается, когда все её враги побеждены; между волнами дают немного здоровья и маны;
- боссовая волна заканчивается только смертью босса; свита появляется каждые 3,5 секунды, но не больше четырёх живых мобов одновременно;
- после победы или поражения можно сразу **попробовать ещё раз**.

## 1. Что нужно установить

- **Node.js 22 LTS** (или Node.js >= 20.19)
- **Git**
- **VS Code** или другая IDE
- аккаунт **GitHub**

Проверка:

```bash
node --version
npm --version
git --version
```

## 2. Первый запуск

```bash
npm install
npm run dev
```

Vite напечатает адрес локального сервера. Обычно это:

```text
http://localhost:5173/
```

Открой его в браузере.

## 3. Где что менять

- баланс и игровые константы (скорость, HP, урон, вес врагов) — `src/game/core/gameConfig.ts`;
- волны: состав, порядок появления и боссовая волна — `src/game/core/waves.ts`;
- параметры финального босса — `src/game/core/bosses.ts`;
- постоянные улучшения: названия, цены и бонусы — `src/game/core/upgrades.ts`;
- профиль, Эхо и сохранение прогресса — `src/game/core/profile.ts`;
- настройки звука и сохранение в `localStorage` — `src/game/core/settings.ts`;
- логика партии (движение, стрельба, спавн, столкновения, состояние экранов) — `src/game/GameScene.ts`;
- общие элементы интерфейса (панели, иконки, кнопки, угли) — `src/game/render/uiKit.ts`;
- отрисовка мира, рыцаря, врагов, босса, эффектов, HUD и меню — папка `src/game/render/`;
- запуск Phaser — `src/game/config.ts`.

Начинай с маленьких изменений:

1. поменяй одно значение в `core/gameConfig.ts` и посмотри, как изменилась игра;
2. добавь одно игровое действие;
3. добавь реакцию игры;
4. добавь цель или результат;
5. добавь препятствие / риск / условие поражения;
6. проверь, что `npm run typecheck` проходит.

## 4. Проверка production build

Перед публикацией:

```bash
npm run build
```

Если команда завершилась без ошибок, итоговая версия находится в папке `dist/`.

Её можно проверить локально:

```bash
npm run preview
```

## 5. Публикация на GitHub Pages

В репозитории уже есть workflow:

```text
.github/workflows/deploy.yml
```

После push в ветку `main` GitHub автоматически собирает проект.

Для первого включения Pages:

1. открой репозиторий на GitHub;
2. **Settings → Pages**;
3. в **Build and deployment → Source** выбери **GitHub Actions**;
4. открой вкладку **Actions** и дождись успешного `Deploy to GitHub Pages`;
5. ссылка на игру появится в deployment и в разделе Pages.
