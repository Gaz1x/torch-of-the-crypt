# Game Dev Starter

Стек: **TypeScript + Phaser + Vite + GitHub Pages**.

Проект — браузерная игра **«Последний факел крипты»**: рыцарь с факелом стоит в темноте крипты, из трещин в стенах появляются тени, свет факела замедляет их, а выстрелы сгустками света расходуют ману. Спуск состоит из **десяти волн на трёх этажах** и заканчивается боссом. Локаций три — «Сухие галереи», «Костяные катакомбы» и «Мёртвый улей»: каждая следующая открывается победой над боссом предыдущей. На этажах свой набор теней и элитных врагов, а после каждого этажа игра замирает и предлагает выбрать один из **даров** — усиление до конца спуска. Финалы разные: **Пожиратель Пламени** гасит факел и бросается в рывок, **Бледный Часовой** держит дистанцию и бьёт веером снарядов, **Мать Роя** постоянно зовёт свиту. Пока босс жив, он не даёт спокойно стоять на месте. Фазы переключаются по очкам: набрано 25 очков — факел гаснет, набрано ещё 15 — он загорается снова, а в темноте персонаж движется медленнее.

Между спусками рыцарь возвращается в полноэкранный **лагерь**. За забег начисляется **Эхо**: `очки / 2 + 20 за каждого убитого босса`; победа приносит полную награду, смерть — половину. Эхо тратится на пять постоянных улучшений — здоровье, стартовую ману, радиус света, скорость перезарядки и множитель Эха. Здоровье и мана упираются в жёсткий потолок, а остальные улучшения получают по дополнительному уровню за каждую новую локацию; поздние локации приносят больше Эха (×1.0 / ×1.2 / ×1.45). Кроме того, у каждой локации есть **мастерство**: победы именно в ней открывают местные перки. Перед спуском можно добровольно включить **испытания** — модификаторы сложности, которые повышают очки и Эхо. В **«Книге стража»** собраны достижения, бестиарий, мастерство и облики рыцаря. Профиль, улучшения, выбранные испытания и облик сохраняются в `localStorage`.

Задание первой практики и домашней работы: [`ASSIGNMENT_01.md`](./ASSIGNMENT_01.md).

### Интерфейс

- **лагерь** — полноэкранный хаб с логотипом, бразиером и сидящим стражем у огня, кнопками справа: «Спуститься», «Улучшения», «Настройки», «Памятка», «Книга» и «Испытания»; в центральной арке время от времени появляются силуэты монстров;
- над кнопкой «Спуститься» — **селектор локаций** тонкой полоской во всю ширину кнопки: шевроны-сегменты по краям, между ними `ЛОКАЦИЯ I · СУХИЕ ГАЛЕРЕИ`; открытые можно переигрывать, закрытые показаны серым;
- в правой колонке лагеря — карточка **«Хроника стража»**: Эхо в шапке, отдельный блок лучшего ранга, построчные рекорды **выбранной локации** (лучший счёт, лучшее время, спуски, победы) и отдельная полоса мастерства (`0/3`–`3/3`);
- **слева — «Страж»**: этаж, здоровье и мана;
- **в центре — «Факел»**: текущая фаза и прогресс до следующей, под ним появляется полоса босса;
- **справа — «Хроника»**: этаж, волна, остаток врагов, очки, время и убийства;
- границу круга света очерчивает двойное кольцо: янтарное при горящем факеле и багровое во тьме;
- у врагов с запасом больше одного удара есть **полоска здоровья**, она появляется после первого попадания;
- рыцарь при движении **покачивается и наклоняется в сторону шага**, из-под ног летит пыль, в лагере фигура только дышит;
- в лагере под описанием мира по очереди сменяются короткие слоганы;
- после каждого из трёх этажей открывается окно **«Дары этажа»** с тремя карточками из четырёх даров: «Скорое пламя», «Раздвоенный луч», «Пронзающая искра» и «Стойкость»; выбранный дар действует до конца спуска;
- начало волны и смена фазы показываются отдельными карточками, которые не перекрывают меню;
- на экранах победы и поражения выставляется ранг: победа без испытаний — **S**, каждое включённое испытание поднимает его на ступень (**SS → SS+ → SSS → SSS+**), смерть всегда даёт **B**; цвет экрана победы зависит от ранга, а строка подсказывает, сколько испытаний не хватает до следующего;
- окно **«Улучшения»** показывает пять постоянных улучшений, их уровень, цену и текущее Эхо;
- **мастерство локации** растёт от побед именно в ней: 3 победы дают +1 к максимуму здоровья здесь, 6 — +10% Эха за местные спуски, 10 — случайный дар на старте (его показывает карточка «Дар мастерства»);
- окно **«Испытания»** включает до четырёх добровольных модификаторов: «Стеклянный страж» (1 HP, ×1.35), «Тусклый факел» (−30% света, ×1.20), «Быстрая тьма» (фазы на 30% раньше, ×1.20) и «Теснота» (+25% врагов и +1 одновременно, ×1.25); множители перемножаются, выбранный набор сохраняется в профиле и повышает очки и Эхо за спуск;
- окно **«Книга стража»** с четырьмя вкладками: 15 достижений (закрытые показаны серым), бестиарий из 10 врагов и 3 боссов со счётчиком убийств, mastery-прогресс по каждой локации и **облики** рыцаря — шесть палитр, которые открываются за достижения (0/3/6/9/12/15) и не дают бонусов; выбранный облик сразу применяется к рыцарю в лагере и в крипте;
- новые достижения за спуск показываются строкой на экране итогов, а уже наигранные условия проверяются при загрузке старого сохранения;
- на экранах лагеря и паузы есть **«Памятка»** с управлением и **«Настройки»** с громкостью музыки и звуков;
- в боссовой волне строка «Осталось» заменяется на **«Свита: N»**.

Вся графика интерфейса рисуется процедурно, без внешних ассетов и шрифтов. Музыкальный трек лежит в `src/assets/audio/soundtrack.mp3`, играет по кругу и запускается после первого клика или нажатия клавиши — этого требуют браузеры.

### Управление

**Компьютер**

- **WASD / стрелки** — движение;
- **курсор мыши** — направление взгляда и прицела;
- **левая кнопка мыши или пробел** — выстрел сгустком света (15 ед. маны);
- **ESC** — пауза: продолжить игру, начать заново или вернуться в лагерь;

**Телефон (горизонтально)**

- **левая половина экрана** — аналоговый стик движения: коснитесь и ведите палец;
- **правая половина экрана** — стик прицела: коснитесь, отведите палец в нужную сторону — рыцарь целится туда и стреляет, пока стик выведен за мёртвую зону;
- рыцарь целится точно по пальцу, а снаряд мягко подтягивается к врагу, который ближе всего к линии огня (узкий конус, не дальше ~420 px); на компьютере доводки нет;
- **верхняя полоса** с панелями не участвует в управлении;
- **кнопка «II»** между панелями — пауза;
- при вертикальном положении экрана появляется подсказка повернуть телефон.

**Общее**

- с убитых врагов падают **кристаллы маны**;
- за спуск начисляется **Эхо**; в лагере его можно потратить на пять постоянных улучшений: здоровье, стартовую ману, радиус света, скорость перезарядки и множитель Эха; здоровье и мана не растут с числом локаций, остальные улучшения получают по уровню за каждую новую локацию;
- внутри круга света враги **сильно замедляются**;
- после попадания рыцарь получает **1 секунду неуязвимости** (мигание и голубое кольцо): в это время касание врага не наносит урона, не отбрасывает врага и не убивает его;
- у каждого врага есть пауза между касаниями, поэтому толпа не снимает всё здоровье за один кадр;
- волна заканчивается, когда все её враги побеждены; между волнами дают немного здоровья и маны;
- боссовая волна заканчивается только смертью босса; свита появляется по таймеру, но не больше нескольких живых мобов одновременно;
- победа над боссом открывает следующую локацию; открытие сохраняется в профиле;
- после победы или поражения можно сразу **попробовать ещё раз**.

## 1. Что нужно установить

- **Node.js 22 LTS** (или Node.js >= 20.19)
- **Git**
- **VS Code** или другая IDE
- аккаунт **GitHub**

Проверка:

```bash
node --version
npm --version
git --version
```

## 2. Первый запуск

```bash
npm install
npm run dev
```

Vite напечатает адрес локального сервера. Обычно это:

```text
http://localhost:5173/
```

Открой его в браузере.

### Запуск на телефоне

`npm run dev` уже слушает всю локальную сеть. Vite напечатает адрес вида `http://192.168.3.8:5173/` — открой его на телефоне, подключённом к той же Wi-Fi сети.

Игра рассчитана на **горизонтальный** экран. Поле масштабируется под окно браузера с сохранением пропорций 16:9, поэтому на нестандартных экранах по краям остаются тёмные полосы. На телефоне включается сенсорное управление: стик движения слева, стик прицела справа, кнопка паузы в верхней полосе.

## 3. Где что менять

- баланс и игровые константы (скорость, HP, урон, вес врагов) — `src/game/core/gameConfig.ts`;
- волны, этажи и локации: состав, порядок появления и боссовая волна — `src/game/core/waves.ts`;
- параметры боссов и их механики — `src/game/core/bosses.ts`;
- постоянные улучшения: названия, цены и бонусы — `src/game/core/upgrades.ts`;
- мастерство локаций: пороги побед и местные перки — `src/game/core/mastery.ts`;
- испытания перед спуском: эффекты и множители — `src/game/core/trials.ts`;
- профиль, Эхо и сохранение прогресса — `src/game/core/profile.ts`;
- настройки звука и сохранение в `localStorage` — `src/game/core/settings.ts`;
- отправка игровых событий в Яндекс.Метрику — `src/game/core/analytics.ts`;
- логика партии (движение, стрельба, спавн, столкновения, состояние экранов) — `src/game/GameScene.ts`;
- общие элементы интерфейса (панели, иконки, кнопки, угли) — `src/game/render/uiKit.ts`;
- отрисовка мира, рыцаря, врагов, босса, эффектов, HUD и меню — папка `src/game/render/`;
- запуск Phaser — `src/game/config.ts`.

Начинай с маленьких изменений:

1. поменяй одно значение в `core/gameConfig.ts` и посмотри, как изменилась игра;
2. добавь одно игровое действие;
3. добавь реакцию игры;
4. добавь цель или результат;
5. добавь препятствие / риск / условие поражения;
6. проверь, что `npm run typecheck` проходит.

### Метрика (Яндекс.Метрика)

Счётчик вставляется в `index.html` сразу после `<body>`, а события отправляет
`src/game/core/analytics.ts` через `track(event, params)`. Номер счётчика задан
константой `COUNTER_ID`. К каждому событию автоматически добавляется
`game_version` (версия из `package.json`), а в dev-режиме события печатаются в
консоль строкой `[analytics]`. Если скрипт Метрики заблокирован, игра просто
работает дальше.

| Событие | Когда | Параметры |
| --- | --- | --- |
| `game_ready` | лагерь показан впервые за визит | — |
| `run_start` | начался спуск | `location` 1–3, `attempt`, `control` |
| `floor_reached` | первый заход на этаж II или III | `floor`, `location`, `attempt` |
| `boss_reached` | вышла боссовая волна | `location`, `attempt` |
| `run_end` | смерть, победа или выход в лагерь | `result`, `location`, `attempt`, `max_floor`, `max_wave`, `duration`, `score`, `kills` |
| `retry_click` | нажали «ЕЩЁ РАЗ» | `after` (`death`/`victory`), `location` |
| `upgrades_opened` | открыли «Улучшения» | `echo` |
| `upgrade_buy` | купили улучшение | `key`, `level`, `cost`, `echo_left` |
| `boon_offer` | показали «Дары этажа» | `floor`, `cards`, `attempt` |
| `boon_pick` | выбрали дар | `boon`, `floor`, `attempt` |
| `mastery_boon` | мастерство локации выдало дар на старте | `location`, `boon` |
| `trial_start` | спуск начался с включёнными испытаниями | `trials`, `multiplier` |
| `trials_changed` | включили или выключили испытание | `trials`, `multiplier` |

Имена целей в интерфейсе Метрики должны совпадать со строками событий.
`attempt` — номер попытки с момента загрузки страницы (1, 2, 3…).

Перед публикацией:

```bash
npm run build
```

Если команда завершилась без ошибок, итоговая версия находится в папке `dist/`.

Её можно проверить локально:

```bash
npm run preview
```

## 5. Публикация на GitHub Pages

В репозитории уже есть workflow:

```text
.github/workflows/deploy.yml
```

После push в ветку `main` GitHub автоматически собирает проект.

Для первого включения Pages:

1. открой репозиторий на GitHub;
2. **Settings → Pages**;
3. в **Build and deployment → Source** выбери **GitHub Actions**;
4. открой вкладку **Actions** и дождись успешного `Deploy to GitHub Pages`;
5. ссылка на игру появится в deployment и в разделе Pages.
