# Game Dev Starter

Стартовый проект для курса **«Проектирование и разработка игровых приложений»**.

Стек: **TypeScript + Phaser + Vite + GitHub Pages**.

Проект — браузерная игра **«Последний факел крипты»**: рыцарь с факелом стоит в темноте крипты, из трещин в стенах появляются тени, свет факела замедляет их, а выстрелы сгустками света расходуют ману.

Задание первой практики и домашней работы: [`ASSIGNMENT_01.md`](./ASSIGNMENT_01.md).

### Управление

- **WASD / стрелки** — движение;
- **курсор мыши** — направление взгляда и прицела;
- **левая кнопка мыши или пробел** — выстрел сгустком света (15 ед. маны);
- с убитых врагов падают **кристаллы маны** — подбирай их, чтобы стрелять дальше;
- внутри круга света враги **сильно замедляются**.

## 1. Что нужно установить

- **Node.js 22 LTS** (или Node.js >= 20.19)
- **Git**
- **VS Code** или другая IDE
- аккаунт **GitHub**

Проверка:

```bash
node --version
npm --version
git --version
```

## 2. Первый запуск

```bash
npm install
npm run dev
```

Vite напечатает адрес локального сервера. Обычно это:

```text
http://localhost:5173/
```

Открой его в браузере.

## 3. Где что менять

- баланс и игровые константы (скорость, HP, урон, вес врагов) — `src/game/core/gameConfig.ts`;
- логика партии (движение, стрельба, спавн, столкновения, состояние экранов) — `src/game/GameScene.ts`;
- отрисовка мира, рыцаря, врагов, эффектов, HUD и меню — папка `src/game/render/`;
- запуск Phaser — `src/game/config.ts`.

Начинай с маленьких изменений:

1. поменяй одно значение в `core/gameConfig.ts` и посмотри, как изменилась игра;
2. добавь одно игровое действие;
3. добавь реакцию игры;
4. добавь цель или результат;
5. добавь препятствие / риск / условие поражения;
6. проверь, что `npm run typecheck` проходит.

## 4. Проверка production build

Перед публикацией:

```bash
npm run build
```

Если команда завершилась без ошибок, итоговая версия находится в папке `dist/`.

Её можно проверить локально:

```bash
npm run preview
```

## 5. Публикация на GitHub Pages

В репозитории уже есть workflow:

```text
.github/workflows/deploy.yml
```

После push в ветку `main` GitHub автоматически собирает проект.

Для первого включения Pages:

1. открой репозиторий на GitHub;
2. **Settings → Pages**;
3. в **Build and deployment → Source** выбери **GitHub Actions**;
4. открой вкладку **Actions** и дождись успешного `Deploy to GitHub Pages`;
5. ссылка на игру появится в deployment и в разделе Pages.

## 6. Структура проекта

```text
.
├── .github/workflows/deploy.yml   # автоматическая публикация
├── src/
│   ├── game/
│   │   ├── config.ts              # конфигурация и запуск Phaser
│   │   ├── GameScene.ts           # основная сцена: состояние и логика партии
│   │   ├── core/
│   │   │   ├── gameConfig.ts      # все игровые константы и баланс
│   │   │   └── entities.ts        # интерфейсы врагов, снарядов, кристаллов маны
│   │   └── render/
│   │       ├── world.ts           # отрисовка крипты и точек появления врагов
│   │       ├── playerArt.ts       # отрисовка рыцаря с факелом
│   │       ├── enemyArt.ts        # отрисовка врагов
│   │       ├── effects.ts         # искры, взрывы, всплывающий текст
│   │       ├── hud.ts             # панель здоровья, маны и счёта
│   │       └── screens.ts         # стартовый экран и экран поражения
│   ├── main.ts                    # точка входа
│   └── style.css                  # страница вокруг canvas
├── AGENTS.md                      # правила для AI-кодинга
├── CHANGELOG.md                   # короткий журнал своей работы
├── TROUBLESHOOTING.md             # если что-то не запускается
├── index.html
├── package.json
├── tsconfig.json
└── vite.config.ts
```
